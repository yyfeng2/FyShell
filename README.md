# FyShell

FyShell 是一款开源免费的跨平台 SSH / 数据库桌面客户端，界面参考 Xshell（终端与文件传输）与 Navicat（数据库管理）的经典风格，基于 Tauri 2 + Vue 3 构建，安装包小巧、启动迅速、内存占用低。

支持 Windows / macOS / Linux。

## 功能特性

- **终端**：SSH（xterm.js + WebGL 渲染）、本地终端（ConPTY）、Telnet、串口终端；多标签、分屏、拖出独立窗口、撰写栏批量发送
- **文件传输**：SFTP 双栏文件管理器（上传/下载/删除/重命名/权限）、传输队列与进度、ZModem（rz/sz）传输、收藏路径
- **数据库**：MySQL 全功能（工作台、SQL 编辑器、数据网格、表设计器、数据传输/生成/同步/结构同步、导入导出、备份还原、用户管理、逆向 ER 模型）、Redis（键浏览、值查看、命令执行）
- **安全**：主密码 + 凭据保险库（ChaCha20-Poly1305 信封加密）、已存连接密码全量加密、明文存量自动迁移
- **效率**：快捷键自定义、快捷命令库、SSH 隧道管理、地址栏快捷连接、会话日志落盘、自动更新

## 下载安装

从 [GitHub Releases](https://github.com/yyfeng2/fyshell/releases) 下载：

| 类型 | 文件 | 说明 |
|---|---|---|
| 安装包 | `FyShell_x.y.0_x64-setup.exe` | NSIS 安装向导，可选安装目录，带自动更新 |
| 便携版 | `FyShell-portable.exe` | 单文件免安装，数据存放在 exe 同级 `data/` 目录 |

### 数据目录

- **安装包模式**：默认 `%APPDATA%\com.fyshell.app`
- **便携模式**：exe 同级 `data/` 目录（数据跟 exe 走，适合 U 盘携带）
- **自定义**：两种模式均支持在 exe 同级放置 `data_dir.conf`（内容为目录路径）指定数据目录；也可通过环境变量 `FYSHELL_DATA_DIR` 指定

## 使用说明

### 连接管理

1. 在左侧导航树点击「新建会话」，填写主机、端口、认证方式（密码 / 私钥 / 交互式 / 不验证 / 跳板机）
2. 可「测试连接」验证后再保存；会话可放入文件夹分组、设置颜色标记
3. 单击树中会话即可连接；同一会话可多开（每次单击为独立连接）
4. 连接失败时 Tab 保留，可直接点「重试」
5. 顶部地址栏支持 `user@host:port` / `host:port` / `user@host` / `host` 四种格式快捷连接

### 终端

- 多标签 + 分屏，可拖出为独立窗口；连接成功 Tab 闪绿提示
- 底部撰写栏（默认关闭）可向「当前 / 全部 / 可见」标签批量发送命令
- 终端内支持搜索、URL 超链接、中键粘贴、双击选词、Ctrl+单击移动光标
- SSH 连接后可直接在终端输入 `rz` / `sz` 触发 ZModem 传输，方向自动识别并弹出文件选择器
- 字体 / 编码 / 配色可在工具栏快捷切换（SSH 连接时显示）

### SFTP 文件传输

- 工具栏「传输」打开双栏文件管理器；也可在会话表单选择「SFTP」会话类型建立独立 SFTP 会话
- 左侧本地、右侧远程，支持拖拽传输、右键「传输到对侧」
- 上传 / 下载完成后对侧列表自动刷新；传输队列支持取消与进度查看
- 权限对话框九宫格与八进制双向联动

### MySQL

- 左侧数据库树：右键菜单涵盖 打开/新建/删除数据库、新建查询、命令列界面、转储 SQL 文件、打印、逆向到模型、在数据库中查找 等 Navicat 风格操作
- **新建查询**：SQL 编辑器（CodeMirror 6）支持高亮 / 补全 / 格式化 / 代码段模板 / 解释（EXPLAIN）/ 仅运行选中；保存常用查询
- **命令列界面**：`mysql>` 风格控制台，上下键历史，`use` / `exit` / `clear` / `help` 内置命令
- **数据网格**：Excel 式编辑、分页/排序/筛选、行内编辑、克隆行、单元格复制为 SQL、列锁定
- **表右键菜单** 21 项：打开表/设计表/新建表/删除/清空/截断/复制表/导入导出向导/转储 SQL/打印/维护（OPTIMIZE/ANALYZE/CHECK/REPAIR）等
- **工具栏数据库工具**（连接后显示）：数据传输 / 数据生成 / 数据同步 / 结构同步

### Redis

- 键浏览支持 pattern 过滤；值查看按类型（string/hash/list/set/zset）自动展示，含 TTL
- 命令栏直接执行任意 Redis 命令

### 安全

- 设置 → 安全 中设置主密码后，已存连接密码全部经 ChaCha20-Poly1305 信封加密存储
- 设有主密码时，重启应用需先解锁才能连接（预期安全行为）
- 已有明文密码在设密时自动迁移加密，无需手动处理

### 设置

设置对话框分 8 个分区：外观（主题/字体）、终端、键盘鼠标、快捷键、SFTP、数据、安全、关于。

- 快捷键支持捕获式自定义（新建会话/关标签/切换标签/复制/剪切/粘贴/全选），可恢复默认
- 「数据」分区可清除查询历史、无效传输数据，或一键删除全部用户数据（恢复首次运行状态，不可恢复）
- 「关于」分区可手动检测更新；「启动时自动检测更新」默认关闭

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+T` | 新建会话（默认，可自定义） |
| `Ctrl+W` | 关闭标签（默认，可自定义） |
| `Ctrl+Tab` | 切换标签 |
| `Alt+1-9` | 跳转第 1-9 个标签 |
| `Alt+F/E/V/T/S/W/H` | 菜单栏导航 |
| `Ctrl+Shift+C / V` | 终端复制 / 粘贴（另有 OS 标准 Ctrl+C/V 两套并存） |

完整列表见菜单栏「帮助 → 快捷键列表」。

## 从源码构建

依赖：Node.js 18+、Rust 1.77+、平台构建工具（Windows 需 WebView2 与 VS Build Tools）。

```bash
npm install
npm run tauri dev      # 开发运行
npm run tauri build    # 构建安装包 + 更新签名产物
```

构建便携版单文件：

```bash
cargo build --release --features portable --manifest-path src-tauri/Cargo.toml
```
