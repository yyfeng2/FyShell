## Design-specificity 判词

**为终端客户端特化的设计，不是通用产品语言。** Xshell/SecureCRT 桌面惯例被系统性移植：菜单栏加速下划线、地址栏独立一整行（四种格式解析）、状态栏分段展示、标签按连接着色、会话树 SSH/数据库分区、左导航+面板的会话选项布局、键位映射与鼠标右键行为可配置。任何 web 产品可原样套用的部分极少。专有性评级：**中高**——对目标用户（Xshell 老手）熟悉度极高，属有意识的惯例复刻而非惰性套用。

**确定性扫描（Assessment B）**：`src/` 全量 58 个 Vue 文件 CLI 扫描零发现（退出码 0）。浏览器动态扫描 4 个代表性视图（主工作区/菜单展开/设置对话框/编辑会话表单）注入成功，仅两类误报：layout-transition 全部命中 Vuetify 框架内部元素（v-list-item__spacer、v-progress-linear 内层、BODY）；text-occlusion 为菜单 overlay 动画期间的瞬态几何测量（overlay 关闭后重扫全部消失）。**应用级 UI 缺陷为零，检测器结果与 LLM 审查「应用代码干净且特化」的判断一致；无遗漏、无误报于审查。** 注入证据完成后已清理（live-server 停止、注入痕迹移除），无残留覆盖层。

## 总体印象

界面基础扎实：操作习惯整体符合 Xshell 类桌面终端老手的预期，右键菜单上下文渲染与删除防护链条是亮点。最大机会在「菜单状态可见性」与「键盘导航惯例」——显示了的加速下划线不响应、开关项无勾选标记，这两处让熟悉桌面惯例的用户产生误导感。

## 优点

1. **右键菜单按节点类型上下文渲染 + 禁用态实时计算**：WorkspaceView.vue 2270-2373 行五种模板（db-leaf/conn/session/section/folder），未连接时灰化数据库操作；FlexTabs.vue 245-268 行 computed 禁用态（本地终端「复制会话」正确禁用、单标签时批量关闭项正确禁用——实查截图确认）。
2. **删除操作的错误预防链条完整**：danger 确认 → 数量提示（「共 N 个」）→ 单条失败不中断整批 → 落盘失败单独预警。
3. **26px 条带节奏与紧凑密度贯穿全局**：MenuBar/ToolBar/AddressBar/StatusBar 四条带统一 26px，信息密度高且视觉连续。

## 优先问题

**[P2] 查看菜单开关项无勾选标记**：「查看」菜单的左导航/命令栏/撰写栏三项是开关，菜单上无任何状态指示，用户无法看出当前是否开启。Xshell 中此类开关项有勾选标记。修法：v-list-item 加 `:active` 态渲染勾选标记或 prepend check icon，从 ui store 读取 quickBarVisible/composeBarVisible/navCollapsed 当前值。建议命令：/impeccable clarify。

**[P2] 菜单加速下划线是纯视觉装饰，Alt+字母无绑定**：菜单标题显示「文件F」「编辑E」等加速下划线，但全局快捷键注册仅 ctrl+t/ctrl+w/ctrl+tab/alt+1~9（WorkspaceView.vue 2063-2072 行），按 Alt+F/E/V/T/S/W/H 不打开菜单。显示下划线却不响应是误导——键盘菜单导航是 Windows 桌面惯例核心路径。修法：实现 Alt+字母 keydown 捕获打开对应菜单，或去掉下划线。建议命令：/impeccable harden。

**[P3] 省略号语义不一致**：Windows 惯例弹对话框的菜单项带省略号。树右键菜单正确（「编辑连接...」「会话设置...」等），但「设置」菜单的「全局设置」「会话设置」「主密码设置」无省略号，「快捷键列表...」又有。修法：统一加省略号。建议命令：/impeccable clarify。

**[P3] 本地终端打开「会话选项」时 SSH 专属面板全量显示**：本地终端 Tab 右键「会话设置」打开 SSH 选项对话框，标题「会话选项 - 本地终端」，但左导航仍显示用户身份验证/SSH 安全性/SSH 隧道/代理等对本地终端无意义的面板。修法：按会话类型过滤导航叶子。建议命令：/impeccable distill。

**[P3] 「窗口」菜单仅一项**：只有「下一个标签 Ctrl+Tab」，没有已开标签列表——Xshell 窗口菜单惯例是列出所有打开的窗口供跳转。修法：动态列出已开标签并勾选指示当前激活。建议命令：/impeccable shape。

## Persona 红旗

- **Alex（电源用户）**：菜单加速下划线（文件F/编辑E…）按 Alt+F 不响应——键盘菜单导航路径被视觉暗示误导后落空。
- **Riley（压力测试）**：标签右键菜单 11 项全量展示，高压下误点「关闭左边/关闭右边」无确认直接批量关闭（固定标签受保护，非固定标签即刻丢失）。
- **Sam（无障碍）**：状态栏连接状态色点对色弱用户难辨，虽有「连接中…/未连接」文字辅助，但色点本身无独立 aria-label。

## 次要观察

- MOUSE_BUTTON_ITEMS 文案「没做什么。」「粘贴剪贴板内容。」是机翻腔（Xshell 原版为「无操作」），建议改为「无操作/粘贴剪贴板」（SettingsDialog.vue 411-414 行）。
- 标签右键菜单图标全部 mdi-*，与「Lucide 图标」约定不同（Vuetify 默认），但内部一致。
- 地址栏 ▼ 下拉列表 max-height="320" 无搜索框，会话多时不易定位。
- 会话树空 Redis 分区常驻显示（无会话时仍显示分区头）。

## 启发性问题

1. 标签右键菜单的「会话设置」与树右键菜单的「会话设置...」打开同一对话框——标签路径为何不预选该标签对应的叶子页？
2. 查看菜单的开关状态是否应直接在菜单项上以勾选呈现，而不是让用户点击后从界面变化推断？
3. 快捷键列表文档化了 Alt+1~9，但菜单加速下划线（Alt+F）未实现——快捷键体系是否应统一注册与文档化，避免「文档有、实现无」？
